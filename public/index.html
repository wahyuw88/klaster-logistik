Tentang Website Dashboard Klaster Logistik

Informasi mengenai tujuan, cakupan, fitur, dan sumber data yang digunakan pada website ini.

DASHBOARD INFORMASI

Media visualisasi data Klaster Logistik

Website ini dikembangkan sebagai media informasi untuk menyajikan ringkasan data dan visualisasi sebaran Klaster Logistik Penanggulangan Bencana di Indonesia. Pengguna dapat melihat informasi secara ringkas melalui dashboard, peta, statistik, dan daftar wilayah.

Tujuan Website

Membantu pengguna memperoleh gambaran sebaran Klaster Logistik, menelusuri informasi berdasarkan wilayah koordinator, dan mengakses referensi terkait melalui satu tampilan yang mudah digunakan.

Fitur Utama

  • Dashboard ringkasan jumlah klaster.
  • Peta sebaran klaster menurut wilayah.
  • Filter Wilayah I, II, dan III.
  • Pencarian dan daftar data klaster.
  • Artikel, berita, dan referensi dasar hukum.

Sumber dan Pembaruan Data

Data dashboard dibaca dari sumber spreadsheet yang terhubung ke aplikasi. Ketepatan informasi mengikuti kelengkapan dan waktu pembaruan sumber data tersebut. Artikel dan referensi hukum ditautkan ke publikasi BNPB serta JDIH BNPB agar pengguna dapat memeriksa sumber aslinya.

Batasan Penggunaan

Website ini merupakan media penyajian informasi dan bukan pengganti dokumen hukum, keputusan pembentukan klaster, sistem pelaporan resmi, atau kanal layanan resmi BNPB dan BPBD. Untuk kepastian informasi, pengguna perlu memeriksa sumber primer yang dicantumkan.
